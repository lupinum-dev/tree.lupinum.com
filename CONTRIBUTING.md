# Contributing

Thank you for improving Lupinum Tree.

Open an issue before a non-trivial change. Small bug fixes and documentation corrections can go directly to a focused pull request.

## Development

Requirements:

- Node.js 22.18 or newer
- pnpm 11

Install and start the app:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Before review, run:

```sh
pnpm verify
```

Explain the result, verification, and main risk in the pull request. Add before-and-after images for visual changes. Update public text when behavior changes.

Do not include credentials, private file names, or customer data in issues, tests, screenshots, or pull requests.
