# Security

Do not report vulnerabilities in a public issue.

Use [GitHub private vulnerability reporting](https://github.com/lupinum-dev/tree.lupinum.com/security/advisories/new). Include the impact, reproduction steps, affected browser or version, and a safe contact method. Do not include production secrets.

We aim to confirm a report within five working days. We will share the next action after we reproduce and assess the issue.

The current `main` branch is the supported version.
